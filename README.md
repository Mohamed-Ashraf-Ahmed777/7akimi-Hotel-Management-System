\# 7akimi Hotel — Management System (C Backend + Web Frontend)



A hotel management system combining a refactored C console backend with an interactive web-based Property Management System (PMS) frontend.



\## Features

\- \*\*C Backend\*\*: Authentication (`users.txt`), room availability (`Room.txt`), room reservations, check-in/check-out billing in EGP, reservation editing, cancellation, search queries, and arrival date reports.

\- \*\*Web Frontend (`hotel\_frontend.html`)\*\*: Interactive room rack, occupancy and revenue metrics, booking with validation, check-out invoices, and `.txt` file import/export.



\## How to Run

1\. \*\*C Console\*\*: Open the project in Code::Blocks and build/run.

2\. \*\*Frontend\*\*: Open `hotel\_frontend.html` in any web browser.
